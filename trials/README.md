# Trials — isolated agents vs. consensus vs. debate

A 3-stage ablation ladder run on a single fixed dataset, to see how much each layer of the
system (aggregation, then debate) actually contributes over the raw specialist agents.

1. **`exp1_isolated_agents.py`** — each of the 4 agents (Genomics/T1, Transcriptomics/T2,
   Pharmacology/T4, Pathway/T3) runs alone on every case. No voting, no debate. Measures
   standalone predictive power per agent.
2. **`exp2_consensus_no_debate.py`** — same 4 agents, same cases, aggregated by majority
   vote (`src.evaluation.ablation_runner.NoDebateEngine`) — no debate rounds, no axiom
   hierarchy.
3. **`exp3_full_debate.py`** — same agents, same cases, run through the real
   `DebateEngine` (peer critique + axiom resolver tiebreak).

## The dataset

All three experiments run on the same 20 cases (`trials/dataset.json`, 2 sets of 10),
generated by:

```
PYTHONPATH=. python trials/build_dataset.py
```

Unlike `data/cases/cases_balanced_a.yaml` etc. (curated so *one* tier has strong signal per
case), this sampler requires that **all four modalities have real data** for every case —
a mutation/CNV row, an expression row, an IC50 row, and a pathway-membership row — verified
directly against the four SQLite DBs. This matters for Experiment 1 specifically: if an
agent lost because it had no data rather than because it reasoned poorly, the isolated
comparison wouldn't be fair. Re-run `build_dataset.py` any time the source DBs change; it's
seeded (`SEED = 42`) so the sample is reproducible.

## Running

```
PYTHONPATH=. python trials/build_dataset.py
PYTHONPATH=. python trials/exp1_isolated_agents.py
PYTHONPATH=. python trials/exp2_consensus_no_debate.py
PYTHONPATH=. python trials/exp3_full_debate.py
PYTHONPATH=. python trials/compare.py
```

Each `exp*` script writes per-case traces to `trials/results/exp*.jsonl` and a metrics
summary to `trials/results/exp*_summary.json`. `compare.py` reads the three summaries and
prints a side-by-side table (best isolated agent vs. consensus vs. debate).

## Caveats

- **n=20 is a pilot, not a validation run.** AUROC/Spearman are noisy at this size — read
  this as a directional signal (which agent is strongest, does aggregation help, does
  debate help further), not a thesis-grade claim. The full mini-validation script
  (`experiments/run_mini_validation.py`) uses 100 cases.
- **Experiment 3 inherits the debate engine's currently-open bugs** (see
  `docs/fixes_needed.html`): a single decisive agent still wins Round 1 without escalating
  to peer critique, and the T3 pathway gate still treats a *missing* self-attestation score
  the same as an *explicitly low* one. Numbers here are a diagnostic of current behavior,
  not the system's fixed ceiling — worth re-running once those are patched.
- All three experiments share one LLM response cache (`src/data/processed/llm_cache.db`),
  so re-runs after the first pass cost no additional API calls.
