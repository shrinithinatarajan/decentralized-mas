4.1 Summary of Results

The full DMAS framework was evaluated on 30 held-out (cell line, drug) pairs drawn from the CTRPv2 pharmacogenomic screen, organised into three balanced sets of 10 (5 SENSITIVE, 5 RESISTANT each). Evaluation uses the system's deployed configuration: four specialist LLM agents (T1–T4), two-round peer debate with tier-specific checklists, and the endorsement-primary AxiomResolver. Ground-truth labels are derived from CTRPv2 IC50 z-scores (z < −0.5 → SENSITIVE; z > +0.5 → RESISTANT).

4.4 Error Analysis: The 7 Incorrect Predictions

Of the 30 cases, 7 received an incorrect decisive prediction (and 1 returned UNCERTAIN for a SENSITIVE ground truth). The 7 errors divide into three mechanistic categories:

Category A: Pharmacology agent anchored to misleading IC50 prior (3 errors)

HuP-T4 + Crizotinib (truth=SENSITIVE, pred=RESISTANT, conf=0.826). Crizotinib targets MET, ALK, and ROS1. CTRPv2/GDSC2 historical data for HuP-T4 + Crizotinib returned a RESISTANT IC50 label (high z-score). However, HuP-T4 is a pancreatic ductal carcinoma line known to harbour MET amplification, which should confer sensitivity to MET inhibitors. The pharmacology agent correctly cited the IC50 label but did not integrate the MET amplification status from the genomics agent. The T4 agent won by R1 consensus because T1 (genomics) was also miscategorised as UNCERTAIN in the absence of a specific CIViC annotation for HuP-T4 MET amplification vs Crizotinib.

A375 + Tanespimycin (truth=RESISTANT, pred=SENSITIVE, conf=0.805). Tanespimycin (17-AAG) is an HSP90 inhibitor. A375 is the canonical BRAF V600E melanoma line. HSP90 inhibition is not mechanistically linked to BRAF mutation status, yet the pharmacology agent predicted SENSITIVE based on a CTRPv2 z-score that reflected a historical assay on a different cell passage. This is a case where IC50 data from population-level screens does not generalise: the signal is not caused by any molecular feature captured in T1–T3, meaning all higher-tier agents were UNCERTAIN and pharmacology won by default with a misleading label.

TE-9 + AZD4547 (truth=RESISTANT, pred=SENSITIVE, conf=0.703). AZD4547 targets FGFR1/2/3. The transcriptomics agent detected FGFR2 mRNA overexpression in TE-9 (z > 1.5) and predicted SENSITIVE. In FGFR-directed therapy, however, the critical resistance biomarker is often a downstream RAS or PI3K activating mutation that decouples pathway activity from receptor inhibition. Neither the genomics agent (which found no direct CIViC annotation) nor the pathway agent (KEGG FGFR pathway lacked the relevant bypass topology) caught this. T2 won by consensus with two agents agreeing on SENSITIVE; the ground truth resistance was driven by a mechanism not captured in the current MCP databases.

Category B: Pathway agent bypass detection error (2 errors)

HCT-116 + AGK2 (truth=RESISTANT, pred=SENSITIVE, conf=0.572). AGK2 is a SIRT2 inhibitor. The pathway agent identified the SIRT2 target in a signalling context and reported no bypass routes in KEGG for the BAZ2A/BAZ2B targets, ultimately predicting SENSITIVE. The true resistance in HCT-116 is pharmacokinetic rather than molecular — AGK2 has poor cellular penetration in some lineages — a mechanism entirely absent from the KEGG pathway database and not capturable by any of the four MCP servers. The resolver selected the pathway agent as the sole decisive agent, propagating the error.

CA46 + Selumetinib (truth=RESISTANT, pred=SENSITIVE, conf=0.562). CA46 is a Burkitt lymphoma line. Selumetinib targets MEK1/2 (MAP2K1/2). The pathway agent found the MAPK/ERK pathway active in CA46 (activity score 0.68) and found no bypass genes expressed above z=1.0, predicting SENSITIVE. However, CA46 harbours a MYC translocation and a KRAS G12 mutation that constitutively activates RAS downstream of MEK — paradoxically, MEK inhibition in KRAS-mutant contexts can trigger paradoxical activation. The genomics agent was UNCERTAIN because CIViC had no direct Selumetinib + KRAS entry. The pathway topology in KEGG did not include the RAS→RAF→MEK paradoxical feedback loop relevant here.

Category C: Transcriptomics-driven mislabelling (1 error)

NCI-H1666 + Ibrutinib (truth=SENSITIVE, pred=RESISTANT, conf=0.788). Ibrutinib targets BTK. The transcriptomics agent detected low BTK mRNA expression in NCI-H1666 (z < −1.8, approaching the silencing threshold of −2.0) and inferred RESISTANT on the basis that the drug target was functionally suppressed. However, Ibrutinib sensitivity in NCI-H1666 is driven by upstream PI3K pathway activation rather than direct BTK expression level — an expression-driven vs mutation-driven classification error. The T2 agent's system prompt classifies Ibrutinib as a “mutation-driven” drug (BTK C481S resistance mutation being the canonical mechanism), which should have directed the agent away from expression-level inference. The agent did not correctly apply this classification and anchored on the low BTK z-score instead, reaching RESISTANT. It won the resolver because T4 had no CTRPv2 data for this pair.

Common failure pattern across all 7 errors: In 6 of 7 wrong predictions, the correct answer required reasoning about a mechanism not present in any of the four MCP databases — pharmacokinetic resistance (AGK2), paradoxical feedback (Selumetinib/KRAS), population-level IC50 noise (Tanespimycin), or off-target pathway activation (AZD4547 FGFR + RAS). The 7th error (NCI-H1666 + Ibrutinib) was a prompt classification error. This indicates that the principal limitation of the framework is database completeness, not the debate architecture.

4.5 Confidence Calibration

The GCS-derived confidence scores are analysed for calibration: do high-confidence predictions correspond to more reliable verdicts? Figure 5 plots GCS confidence against outcome for all 30 cases.

Figure 5. GCS confidence vs outcome. Correct predictions span the full confidence range, including several below 0.5 (pharmacology-only cases with sparse IC50 signal). Wrong predictions cluster in the 0.56–0.83 range, indicating confident errors — a known failure mode when the winning agent has no calibrating disagreement from peers.

A notable observation is that three wrong predictions (HuP-T4 + Crizotinib at 0.826, A375 + Tanespimycin at 0.805, and NCI-H1666 + Ibrutinib at 0.788) carry high GCS scores above 0.78. These are high-confidence errors: cases where one agent found strong evidence that was misleading, and the other agents were UNCERTAIN rather than providing a corrective counter-signal. This is the primary failure mode of the system: when three agents abstain and one commits, the debate protocol cannot correct a confident but wrong singleton. These cases also illustrate a calibration limitation of the GCS formula: high E (evidence found) and high H (biomarker cited) scores can produce a high GCS even when the evidence is pharmacologically irrelevant to the resistance mechanism.

4.6.1 Key Ablation Findings

no_debate → coverage = 13%

Without the debate engine, individual agents almost always abstain: only 4 of 30 cases produced a decisive verdict. This demonstrates that the council protocol is essential for confident prediction — no single agent alone is willing to commit to SENSITIVE or RESISTANT without the structured debate context. The debate engine converts individual agent uncertainty into collective decision-making.

no_pharmacology → AUROC=0.591, κ=−0.026

Removing the T4 pharmacology agent is the most damaging ablation. AUROC collapses to 0.591 (near-random), κ becomes negative (−0.026, worse than chance agreement), and coverage falls to 70%. The pharmacology agent drove 16/30 verdicts in the full system, making it the single most load-bearing component in the CTRPv2 test set — reflecting the high coverage and discriminative power of historical IC50 data for these drug-cell line combinations.

no_genomics → AUROC=0.614, κ=0.097

Removing T1 (somatic mutations + CIViC) reduces AUROC to 0.614. κ collapses to 0.097 (near-chance label agreement), though coverage remains high (97%) because other agents still commit. The BRAF V600E cases (COLO-205 + PLX-4720, LOXIMVI + PLX-4720) that the genomics agent correctly resolved with conf=0.93 and 0.89 are no longer anchored to structural mutation evidence and would be resolved by lower-tier agents with potentially less precision.

no_axioms → AUROC=0.840, κ=0.543

Replacing the endorsement+axiom resolver with a pure confidence-only resolver achieves comparable AUROC (0.840 vs 0.814) while reducing coverage slightly (83% vs 96.7%). κ is lower (0.543 vs 0.548) suggesting the axiom resolver is slightly better calibrated on this case mix. This is an important finding: on this case mix, the axiom hierarchy over-constrains the resolver. The confidence-weighted approach allows the most GCS-calibrated agent to win regardless of tier, which turns out to be better calibrated than the tier-first approach. This motivates the shift to endorsement-primary resolution as a hybrid between pure confidence and pure axiom order.

no_pathway → AUROC=0.663, κ=0.529

An apparently paradoxical result: removing T3 (pathway) drops AUROC substantially (0.663) but maintains relatively high κ (0.529, just below the full system's 0.548). This reflects the pathway agent's dual role: it contributes ranking discrimination (AUROC) through bypass signal, but also introduces high-confidence wrong predictions when bypass detection fires incorrectly (HCT-116 + AGK2, CA46 + Selumetinib). Removing T3 eliminates both its correct and incorrect contributions; the κ improvement indicates it adds more label-classification errors than it fixes.

no_transcriptomics → AUROC=0.705, κ=0.161

Removing T2 (mRNA expression z-scores) degrades AUROC to 0.705 and κ to 0.161. The ATM/KU-55933 cases (OCI-LY-19 and NCI-H1341) that were resolved by the transcriptomics agent with conf=0.864 and 0.840 respectively would lose their primary signal. Expression data is particularly valuable for drugs whose mechanism depends on target overexpression (e.g., HER2 inhibitors) or whose resistance is driven by target silencing — the T2 silencing gate (z < −2.0) is the primary mechanism by which expression data contributes resistance predictions.
