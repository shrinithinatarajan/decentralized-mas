Research Overview
Computational Oncology  ·  Multi-Agent AI
Decentralised Multi-Agent Framework
for Cancer Drug Resistance Prediction
Current AI tools return a probability score with no explanation of which evidence drove the prediction or how conflicting signals were resolved. This project builds a virtual tumour board where four specialised agents debate under a formal biological hierarchy before producing an auditable verdict.

Architecture
Five-Layer System Architecture
1
Data SubstrateFoundation
GDSC2 (IC50 drug response) · CCLE/DepMap (mutations, RNA expression, CNV) · KEGG (pathway maps) · ChEMBL (drug mechanism of action) — loaded into four modality-specific SQLite databases
2
MCP ServersA2T Protocol
Four typed, schema-validated servers expose query tools to agents. Every data request returns structured JSON — structurally preventing agents from citing data not present in the database
3
Specialist AgentsIndependent Analysis
Genomics · Transcriptomics · Pharmacology · Pathway — each agent queries only its own MCP server and submits a structured EvidencePack (verdict, confidence, tier, key findings)
4
Consensus ProtocolA2A Debate
ConflictDetector identifies disagreements · AxiomResolver applies the Hierarchy of Truth · DebateEngine runs up to 3 rounds with forced resolution and dissent logging if consensus is not reached
5
Output & AuditFinal Prediction
Final verdict (Sensitive / Resistant / Uncertain) · Confidence score · Full debate trace naming every axiom invoked, every agent overridden, and every dissent preserved
