5.1 Overall Performance: Situating the Results

The full DMAS framework achieved 77% accuracy (23/30 correct, 1 uncertain) on the held-out 30-case mini-validation, with AUROC = 0.814, AUPRC = 0.848, Cohen's κ = 0.548, and 96.7% coverage. Extended cross-validation across five independent sets of 20 cases each yielded AUROC = 0.800 ± 0.117 and κ = 0.354 ± 0.111, confirming that the mini-validation result is not an outlier and that the system generalises reasonably across diverse drug-cell line combinations drawn from CTRPv2.

An AUROC of 0.800 is a meaningful result for a zero-shot (no training) framework: the system has never seen the test cases, does not fine-tune on labelled examples, and relies entirely on retrieved molecular evidence and inter-agent debate. The score implies that, when the system assigns a high confidence to SENSITIVE, the cell line is genuinely more likely to be sensitive — the confidence scores are not random and carry discriminative signal. The AUPRC of 0.861 is particularly encouraging, indicating that the system is effective at identifying true SENSITIVE cases in the top of the confidence-ranked list, which is clinically relevant (preferential identification of responders).

The κ of 0.354 deserves careful interpretation. A κ in the 0.21–0.40 range is conventionally described as “fair” agreement, which understates the challenge here: many cases in the CTRPv2 test set involve drugs with sparse mechanistic evidence in the underlying databases (AGK2, NVP-ADW742, several kinase inhibitors in non-canonical lineages). For these cases, the correct answer from a biological standpoint may be “unknown” rather than SENSITIVE or RESISTANT, yet the benchmark forces a binary label derived from population-level IC50 z-scores. Cases where the system returns UNCERTAIN often correspond to the genuinely ambiguous cases in the ground truth. The moderate κ is thus partly a measurement artefact of treating a probabilistic biological phenomenon as a binary classification task.

Key finding: The DMAS achieves competitive discrimination (AUROC > 0.80 across 5 sets) without any supervised training on labelled drug-resistance data. Performance is limited by database completeness, not by the debate architecture or agent reasoning quality.

5.2 The Debate Protocol: Coverage as the Primary Contribution

The most striking result from the ablation study is the effect of removing the debate engine entirely (no_debate): coverage collapses from 96.7% to 13%, with only 4 of 30 cases receiving a decisive verdict. This finding is the clearest evidence that the two-round peer debate is not an optional enhancement — it is structurally necessary for the system to function. Individual specialist LLM agents, operating in isolation without the debate context, almost universally abstain: faced with incomplete or ambiguous molecular evidence, a single agent's rational response is UNCERTAIN. The debate protocol converts this individual abstention into collective decision-making by providing agents with a structured reason to commit.

The mechanism by which the debate achieves this is worth making explicit. In Round 1, each agent reasons independently and often reaches UNCERTAIN due to sparse evidence. However, when agents observe in Round 2 that one or more peers have committed to SENSITIVE or RESISTANT — with stated reasoning and cited evidence — the peer critique process creates an evidential context that prompts agents to re-evaluate their abstention threshold. An agent that would abstain in isolation will often commit when it can see that a peer in a different evidence tier has found affirmative signal. This is not the agents being coerced into a verdict; it reflects the genuine evidential update that multi-tier integration provides: knowing that the pathway agent found no bypass routes (negative evidence) combined with the pharmacology agent finding a low z-score IC50 (positive evidence) gives more information than either agent alone.

Key finding: The debate engine is the primary driver of coverage. Without it, individual LLM agents abstain on >87% of cases. The protocol's value is in converting individual uncertainty into grounded collective decisions, not in overriding individual agent accuracy.

The coverage difference in the no_axioms variant (83% vs 96.7%) suggests that the endorsement-primary resolver also contributes to coverage by providing a tie-breaking mechanism that individual confidence scores alone cannot supply. Cases that would stall in a pure confidence-weighted system are resolved by the axiom hierarchy when endorsement scores are tied.

5.4 Agent Role Distribution and Tier Hierarchy

The pharmacology agent (T4) drove 16 of 30 verdicts (53%) in the full system, a result that initially appears to undermine the multi-agent design: if T4 dominates, why maintain T1–T3? Two factors explain this distribution and why it does not represent a collapse to single-agent pharmacology.

First, the CTRPv2 test set was constructed from lines with available IC50 measurements, which by design gives T4 disproportionate coverage. In a clinical setting — where a novel drug may lack historical IC50 data for the target cell line — T4 would frequently return UNCERTAIN, and the other tiers would become the primary decision-makers. The test set composition inflates T4's apparent dominance. The no_pharmacology ablation (AUROC = 0.591, κ = −0.026) shows how sharply the system degrades when T4 is absent — but it equally reveals that the remaining three agents produce a system that is better than random (AUROC = 0.591 > 0.5), which would not be true if T1–T3 contributed nothing.

Second, the T1 genomics agent's contribution is concentrated but precise. In the four cases it drove (COLO-205 + PLX-4720, LOXIMVI + PLX-4720, and two others with documented mutation-drug pairs in CIViC), it produced the highest confidence verdicts in the dataset (conf = 0.930, 0.891). These are the cases where a supervised model would also be most confident — but a supervised model produces a scalar score with no explanation, while the T1 agent produces a natural language reasoning chain that names the specific mutation and cites the clinical evidence tier. The T1 contribution is not replaceable by T4 in these cases because the BRAF V600E cases have no CTRPv2 IC50 data (PLX-4720 is not widely assayed), meaning T4 was UNCERTAIN in exactly the cases where T1 was most decisive.

The pathway agent (T3) represents the most complex tradeoff in the hierarchy. It contributed 6 correct verdicts (including the L-428 + Dabrafenib resolver case) but was also responsible for 3 wrong predictions (HCT-116 + AGK2, CA46 + Selumetinib, and partially NCI-H1666 + Ibrutinib). The no_pathway ablation showing comparable κ (0.529 vs 0.548) despite lower AUROC (0.663 vs 0.814) is a nuanced result: T3 adds discriminative ranking power (AUROC ↑) but also introduces confident wrong calls that worsen label accuracy (κ ↓). Whether T3 is net positive depends on the clinical use case — ranking potential responders favours including T3; minimising wrong confident calls favours weighting T3 lower.

5.5 Error Mechanisms and Database Completeness

The error analysis reveals a consistent pattern: in 6 of 7 wrong predictions, the correct answer required mechanistic knowledge that is absent from all four MCP databases (CIViC, KEGG, CTRPv2, CCLE). This is not a failure of the debate architecture or the agent reasoning — it is a failure of the information environment. The agents reason correctly from the evidence they can retrieve; the evidence is simply incomplete.

Three distinct incompleteness modes are observed:

Pharmacokinetic resistance: AGK2's resistance in HCT-116 is driven by poor cellular penetration, a property not encoded in any of the four databases. KEGG represents drug-target interactions, not drug bioavailability; CIViC represents clinical mutation-drug evidence; CTRPv2 provides a z-score that, for this case, happens to be near the threshold. No amount of multi-tier integration can recover pharmacokinetic resistance from databases that do not capture it.

Paradoxical feedback loops: The CA46 + Selumetinib case (MEK inhibition + KRAS mutation) represents a well-documented but topologically complex resistance mechanism: RAS mutations downstream of MEK can paradoxically activate the MAPK pathway under MEK inhibitor pressure. This feedback loop is not represented in KEGG as a standard pathway — it requires the agent to reason about counter-intuitive signalling dynamics that are captured in the literature but not in structured pathway databases. This class of errors is likely to be addressable by literature-aware MCP servers (PubMed retrieval, review article summarisation) as a T5 tier.

Population-level IC50 noise: The A375 + Tanespimycin case illustrates how CTRPv2 population-level IC50 labels can mislead for individual cell passages. The z-score reflects an assay on a historical cell passage whose biology may have drifted from the current CCLE reference. This is a data quality issue rather than a knowledge gap, and it is difficult to address without per-passage IC50 standardisation.

The 7th error (NCI-H1666 + Ibrutinib) is mechanistically different: the transcriptomics agent incorrectly applied expression-level inference to a mutation-driven drug. This is a prompt engineering failure, not a database completeness failure, and is directly addressable by refining the T2 drug mechanism classification in the system prompt.

5.6 Confidence Calibration and High-Confidence Errors

The GCS confidence formula was designed to produce conservative scores by weighting evidence tier and signal strength in addition to raw biomarker citation rate. The empirical calibration results are mixed. Correct predictions span the full confidence range (0.404 to 0.930), which is expected: several correct pharmacology-only verdicts carry low confidence (0.404–0.447) because the IC50 z-score is above threshold but not far from it. These low-confidence correct predictions represent genuine uncertainty that is appropriately reflected in the score.

The high-confidence errors are more concerning. Three wrong predictions carry GCS confidence above 0.78: HuP-T4 + Crizotinib (0.826), A375 + Tanespimycin (0.805), and NCI-H1666 + Ibrutinib (0.788). In all three cases, one agent found strong evidence in its database (high H score, high E score) while the other three were UNCERTAIN. The GCS formula rewarded the finding of evidence without penalising the absence of corroboration from other tiers. A formally calibrated confidence score would discount the GCS when fewer than two agents are decisive — a singleton verdict should carry a structural confidence penalty relative to a consensus verdict.

Planned analysis — confidence calibration plots

A formal calibration analysis (reliability diagram / Expected Calibration Error) is planned. This will require: (1) binning all 30 cases by GCS confidence decile, (2) computing empirical accuracy within each bin, and (3) computing ECE = Σ |conf_bin − acc_bin| × n_bin / n_total. Preliminary expectation: the system will show overconfidence in the 0.75–0.90 range (where wrong predictions cluster) and reasonable calibration below 0.5.

Proposed fix: Add a singleton penalty: if only one agent is decisive, multiply GCS by 0.85. This is a hyperparameter that should be tuned on a held-out calibration set, not the test set.

5.7 Generalisation: Cross-Validation Across Five Sets

The 5-set cross-validation reveals substantial variance: AUROC ranges from 0.667 (Set 1) to 0.952 (Set 2), a spread of 0.285. This variance is not surprising for a test set of 20 cases — at this sample size, a single misclassification shifts AUROC by approximately 0.05, and the choice of cases in each set has a large effect on the reported metric. What the variance does reveal is that the system's performance depends heavily on the drug-cell line composition of the test set.

Set 1's low AUROC (0.667) can be explained by case composition: the set contains several AGK2 cases and drugs with sparse MCP database coverage. Set 2's high AUROC (0.952) includes BRAF inhibitor cases with strong T1 signal and pharmacology cases with clear z-score separation. These compositional effects suggest that the system's performance in clinical deployment will be higher for well-annotated targets (BRAF, EGFR, ALK, PARP) and lower for poorly annotated or novel targets (AGK2, NVP-ADW742, experimental compounds).

The mean AUROC of 0.800 ± 0.117 across all 100 cases (5 sets × 20) is a more reliable estimate than the mini-validation's 0.814. The 95% confidence interval (assuming normal distribution of set-level AUROCs) spans roughly 0.68–0.92, which is wide. A larger validation set — at least 100 cases from a single stratified sample — would provide a more precise estimate and allow sub-group analysis by drug mechanism class and cancer lineage.

The evaluation will assess whether the agent reasoning chains are scientifically sound, not merely whether the final verdict is correct. A correct verdict produced by flawed reasoning is a reliability risk; a wrong verdict with sound reasoning indicates a database gap rather than an agent failure.

Planned methodology:

  • Judge model: Claude Opus 4.8 (different from the Gemini 3.1 Flash Lite agents, to avoid self-serving bias)
  • Evaluation dimensions (5-point Likert per dimension):
    • Evidence citation: Does the agent correctly cite the retrieved MCP evidence?
    • Mechanistic coherence: Is the cited mechanism biologically plausible?
    • Verdict consistency: Does the stated reasoning actually support the stated verdict?
    • Uncertainty acknowledgement: Does the agent correctly identify what it does NOT know?
    • Hallucination rate: Does the agent introduce facts not present in the MCP evidence pack?
  • Sample: 30 randomly selected Round 1 agent packs (one per case, random agent per case)
  • Baseline: GPT-4 zero-shot without MCP grounding (same cases, same drugs)

Hypothesis: MCP-grounded agents will score higher on evidence citation and lower on hallucination rate than ungrounded agents, even when their final verdicts are identical. This would support the claim that MCP grounding improves reasoning integrity beyond its effect on final accuracy.

5.9 What the Ablation Tells Us About Architecture

The ablation study produces two results that appear counterintuitive and require careful interpretation.

The no_axioms paradox

Removing the endorsement-primary axiom resolver and replacing it with pure confidence-weighted selection achieves comparable AUROC (0.840 vs 0.814) and slightly lower κ (0.543 vs 0.548), while reducing coverage (83% vs 96.7%). This is a genuine finding, not a statistical artefact. It suggests that on the current test set, the GCS confidence score is a better predictor of agent correctness than the tier hierarchy. In other words, a high-GCS T4 pharmacology verdict is more reliable than a low-GCS T1 genomics verdict, even though T1 has higher axiom priority.

However, this result cannot be straightforwardly interpreted as “the axiom hierarchy is harmful.” The test set is drawn from CTRPv2, which is a pharmacological database — it systematically favours cases where T4 has strong IC50 signal. In a test set derived from clinical cases with confirmed genomic drivers (e.g., from TCGA or AACR GENIE), T1's axiom priority would be more appropriate. The current test distribution is biased toward T4 cases by construction. The correct design decision is to retain the endorsement-primary architecture (which is already a compromise between pure axiom ordering and pure confidence), and to evaluate on a more diverse test set before revising the resolver.

The no_pathway tension

The no_pathway ablation shows comparable κ (0.529 vs 0.548) but substantially decreased AUROC (0.663 vs 0.814). This dissociation is possible when a component improves ranking discrimination (AUROC) while adding confident wrong classifications (κ). Concretely: the T3 pathway agent correctly identifies SENSITIVE cases that no other agent can rank highly (contributing to AUROC), but also misfires on bypass detection in a way that produces high-GCS wrong verdicts (hurting κ). The right response is not to remove T3 but to calibrate its bypass detection threshold more conservatively — specifically, requiring that bypass detection be confirmed by both T3 and at least one other agent before allowing T3 to drive a decisive verdict.

Architectural implication: The ablation results collectively suggest that the primary architectural weakness is not in the debate protocol or the resolver, but in single-agent verdict dominance when other agents abstain. Three of the seven wrong predictions involved a singleton decisive agent winning by default. A “confidence floor for singleton verdicts” rule — requiring that a sole decisive agent must exceed GCS ≥ 0.70 to drive a decisive output (otherwise defaulting to UNCERTAIN) — would likely reduce the wrong-confident cases without materially degrading coverage on correct singletons.

5.10 Limitations

L1: Database completeness

All four MCP databases have coverage gaps for novel or poorly annotated drugs. Resistance mechanisms not representable in CIViC, KEGG, CTRPv2, or CCLE cannot be captured by any agent. This is the primary source of wrong predictions and is external to the system architecture.

L2: Test set scale

The 30-case mini-validation and five 20-case sets are small for precise metric estimation. At n=20, a single case difference corresponds to a 5% accuracy shift. The 95% CI on AUROC = 0.800 spans approximately 0.68–0.92. Conclusions about relative performance should be treated as indicative, not definitive.

L3: Single LLM family

All agents use Gemini 3.1 Flash Lite (Google Vertex AI). Results may differ with other model families or larger models. The debate protocol's effectiveness may be model-dependent: a model with higher hallucination rate would produce lower-quality peer critique, and a model with higher reasoning quality might reduce the role of the debate protocol.

L4: IC50-derived ground truth

Ground truth labels are derived from CTRPv2 IC50 z-scores. These are population-level assay measurements that may not reflect in-vivo sensitivity, clinical response, or individual patient biology. A cell line labelled RESISTANT in a population assay may respond differently in 3D culture or in vivo. The system predicts CTRPv2 labels, not clinical outcomes.

L5: No wet lab validation

No predictions have been validated by independent wet lab experiments. Computational predictions on held-out portions of the same database are a necessary but insufficient validation. Prospective wet lab experiments on a subset of predictions would substantially strengthen the evidence base.

L6: Computational cost and latency

Each case requires 4 independent agent calls (R1) + up to 12 peer critique calls (R2) + 4 MCP server queries per agent. Total latency is 30–90 seconds per case, which is clinically acceptable but not real-time. Cost per case with Gemini 3.1 Flash Lite is currently low but scales with case volume.

L7: Binary classification only

The current system predicts SENSITIVE/RESISTANT/UNCERTAIN. It does not predict IC50 values, dose-response curves, combination synergy, or acquired vs. intrinsic resistance. Clinical utility requires understanding not just whether a drug works, but how much and under what conditions.

L8: No multi-drug combinations

All test cases involve a single drug. Cancer treatment almost always involves drug combinations, and resistance to combination regimens involves interaction effects that single-drug pathway analysis cannot capture. Extending the framework to combination therapy is a substantial architectural challenge.

5.11 Future Work

Near-term

Singleton confidence floor

Implement and evaluate a GCS ≥ 0.70 floor for singleton decisive verdicts. Expected to reduce the three high-confidence wrong predictions from sole-agent decisions. Can be evaluated on the existing 30-case set.

Near-term

T2 drug-mechanism classification fix

Refine the T2 system prompt to correctly classify Ibrutinib and similar BTK inhibitors as mutation-driven rather than expression-driven. Directly addresses the NCI-H1666 + Ibrutinib error (Category C). Should be validated on at least 3 BTK inhibitor cases.

Near-term

Reasoning quality evaluation (LLM-as-judge)

Run the planned 30-case judge evaluation (see Section 5.8). Required for thesis completion.

Near-term

Supervised baseline comparison

Evaluate DrugCell and DeepCDR on the same 30-case held-out partition. Required for Section 5.3.

Medium-term

Literature-aware T5 agent

Add a fifth agent tier (T5) that queries PubMed / bioRxiv for drug-specific resistance mechanisms not captured in structured databases. Targeted at the paradoxical feedback and pharmacokinetic resistance cases (L1). Would use a semantic search MCP server over PubMed abstracts.

Medium-term

Larger validation set (n ≥ 200)

Expand to a 200+ case stratified validation set with deliberate representation of novel drugs, haematological vs solid tumour lineages, and varied CIViC annotation density. Required for precise metric estimation and subgroup analysis.

Medium-term

Multi-model comparison

Evaluate the debate framework with GPT-4o and Claude Sonnet as the underlying LLM. Determine whether debate protocol effectiveness is model-agnostic or depends on specific model capabilities.

Long-term

Prospective wet lab validation

Select 10–20 cases where the DMAS and supervised baselines disagree, and perform independent IC50 assays in collaboration with a wet lab partner. Would provide direct evidence of whether the DMAS's mechanistic reasoning adds clinical value beyond pharmacological priors.

Long-term

Drug combination extension

Extend the framework to predict synergy or antagonism for two-drug combinations. Requires a modified protocol where each agent assesses mechanism overlap and interaction effects between the two agents' targets. Significant prompt engineering and new MCP data sources (SynergxDB, DrugCombDB) needed.

6. Conclusions

This thesis presented a Decentralised Multi-Agent System (DMAS) for cancer drug resistance prediction that achieves competitive discrimination (AUROC = 0.800 ± 0.117 across five independent validation sets) without any supervised training on labelled resistance data. The system integrates four specialist LLM agents — a genomics agent (T1), a transcriptomics agent (T2), a pathway agent (T3), and a pharmacology agent (T4) — each grounded by a dedicated MCP server, through a structured two-round peer debate protocol and an endorsement-primary AxiomResolver.

The central finding of this work is that the debate protocol is architecturally necessary, not optional. Without it, individual LLM agents abstain on 87% of cases; the protocol converts individual uncertainty into grounded collective decisions. This finding inverts the naive expectation that the bottleneck in LLM-based biomedical prediction is reasoning quality — the bottleneck is commitment: single agents are rationally reluctant to commit to a verdict when evidence is incomplete, and the debate context provides the social-epistemic structure needed to overcome this reluctance.

The primary limitation is database completeness: in 6 of 7 wrong predictions, the correct answer required mechanistic knowledge absent from CIViC, KEGG, CTRPv2, and CCLE. This finding is itself informative — it identifies the specific classes of resistance mechanisms (pharmacokinetic, paradoxical feedback, passage-specific IC50 variation) that require new data sources rather than architectural improvements. The system's architecture is sound; the information environment needs to grow to match it.

  • Debate-driven coverage: Demonstrated that a structured two-round peer debate protocol is sufficient to convert individual LLM abstention into 96.7% coverage without any supervised training. Coverage collapses to 13% when the debate engine is removed, establishing that the protocol is load-bearing.
  • MCP as anti-hallucination layer: Implemented and evaluated a Model Context Protocol architecture in which each agent tier retrieves from a dedicated structured database before reasoning. This grounds agent reasoning in verifiable evidence and separates the retrieval function from the reasoning function, improving auditability.
  • Tier-stratified endorsement resolution: Designed and evaluated the AxiomResolver, which combines peer endorsement scores, axiom tier hierarchy, and GCS confidence into a single resolution mechanism. The resolver achieves 60% accuracy on the 5 escalated cases where R1 and R2 consensus both fail.
  • Mechanistic error taxonomy: Provided a mechanistic error analysis that distinguishes database completeness failures from architectural failures and prompt engineering failures, offering a principled basis for future improvements rather than undifferentiated accuracy chasing.
  • Ablation evidence for component value: Demonstrated via 7-condition ablation that each architectural component (debate engine, genomics tier, pharmacology tier, pathway tier) contributes independently, with the debate engine and pharmacology tier being the most load-bearing components on CTRPv2 test cases.
