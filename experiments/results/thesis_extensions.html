Extension 1
Continuous Resistance Score with Calibration Analysis
The published system outputs a binary SENSITIVE / RESISTANT verdict. This extension derives a continuous resistance probability from per-agent GCS values using Hierarchy-of-Truth tier weights, enabling a proper calibration analysis.
Before (published)
Binary classification only
System outputs SENSITIVE, RESISTANT, or UNCERTAIN with a single final_confidence float. No calibration analysis was performed; ECE and reliability diagrams were not reported.
After (this extension)
Tier-weighted continuous probability
Each agent's GCS is sign-flipped by verdict direction and aggregated using Hierarchy-of-Truth tier weights. A sigmoid maps to resistance probability in [0,1], enabling AUROC, AUPRC, and ECE reporting.

Extension 2
Cross-Tier Leakage Rate Quantification
The paper identified "cross-tier leakage" (agents citing parametric knowledge not in MCP output) as a qualitative limitation but never measured it. This extension uses a Gemini judge to classify all 142 auditable findings as Grounded, Inferred, or Leaked.
Before (published)
Qualitative description only
Limitations section: "The primary faithfulness failure mode is cross-tier leakage. Agents cite mechanistically correct facts from parametric knowledge that were not returned by the assigned MCP tool call." No rate was computed.
After (this extension)
Quantified: 8.5% leakage rate
142 findings audited across 100 cases. Fast string-match pre-filter avoids LLM calls for grounded values; Gemini judge evaluates borderline cases. Leakage isolated to the transcriptomics agent (21.8%); genomics agent has 0% leakage.
